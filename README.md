# IdeaVault 💡

IdeaVault is a Python app for recording and keeping your ideas. Save every idea that comes to mind in one place so it never gets lost.

## Features

- Record new ideas
- Keep all your ideas in one place

## Requirements

- Python 3.x

## Installation and Usage

```bash
git clone https://github.com/fatemehjafarii24/IdeaVault_By_Ai.git
cd IdeaVault_By_Ai
python IdeaVault.py
```

## How to Use

Run the program and follow the on-screen options to enter your idea.
