# IdeaVault 💡

IdeaVault یک برنامه‌ی پایتونی برای ثبت و نگهداری ایده‌هاست. هر ایده‌ای که به ذهنتان می‌رسد را در یک‌جا ذخیره کنید تا هیچ‌وقت گم نشود.

## ویژگی‌ها

- ثبت ایده‌های جدید
- نگهداری ایده‌ها در یک مکان

## پیش‌نیازها

- Python 3.x

## نصب و اجرا

```bash
git clone https://github.com/fatemehjafarii24/IdeaVault_By_Ai.git
cd IdeaVault_By_Ai
python IdeaVault.py
```

## نحوه‌ی استفاده

برنامه را اجرا کنید و طبق گزینه‌هایی که نمایش داده می‌شود، ایده‌ی خود را وارد کنید.
